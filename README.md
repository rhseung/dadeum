# dadeum

AI 가 쓴 한국어 문서를 뜻이 분명한 문장으로 다시 쓰는 Claude Code 스킬입니다.

생략된 문장 성분을 되살리고, 조사와 어미를 채우고, 비유적 어휘를 일반 어휘로 바꾸고,
터미널에서 정렬을 깨뜨리는 비ASCII 문장부호를 정리합니다. 사실과 수치, 주장, 서술
순서는 건드리지 않습니다. 문체와 문장 구조만 다룹니다.

## 설치

```sh
claude plugin marketplace add rhseung/dadeum
claude plugin install dadeum@rhseung
```

## 사용법

고칠 문서의 경로를 주거나 텍스트를 붙여넣고 요청하면 됩니다.

```
README.md 다듬어줘
이 PRD 에서 AI 말투 좀 없애줘
docs/ 아래 문서들 dadeum 적용해줘
```

파일을 고칠 때에는 먼저 원본을 확보한 뒤에 수정하고, `git diff` 로 결과를 보여줍니다.

## 규칙

| 항목 | 내용 |
| --- | --- |
| 적용 범위 | 본문 산문, 제목, 목록 항목, 표의 설명 칸 |
| 제외 범위 | 코드 블록, 코드 주석, 변수명, 커밋 메시지, 인용문, 경로와 식별자 |
| 문장 단위 | 뜻을 담은 성분을 빼지 않는다. `~의` 를 겹쳐 쓰지 않는다. 종결어미로 문장을 맺는다 |
| 구 단위 | 조사와 어미를 살린다. 한자어에 조사를 붙여 관계를 드러낸다. 비유적 어휘를 쓰지 않는다 |
| 기술 문서 | 표시어는 산문에만 쓴다. 기술 용어는 영어 원어로 둔다. 섹션 제목은 한자어 명사형으로 쓴다 |

의미를 바꾸지 않는 것이 가장 강한 제약입니다. 문맥에서 생략된 성분을 확실하게 복원할
수 없으면 그 문장은 그대로 두고 어느 문장이었는지 알립니다. 변경량이 원문의 절반을
넘어가면 문체 교정의 범위를 벗어난 것으로 보고 작업을 멈춥니다.

전체 규칙은 [`dadeum/skills/dadeum/SKILL.md`](dadeum/skills/dadeum/SKILL.md) 에 있습니다.
외부 파일에 의존하지 않으므로 이 파일 하나만 읽으면 됩니다.

## 예시

각 예시는 `.diff` 파일입니다. 앞머리에 어떤 규칙이 어느 구간을 고쳤는지 적어 두었고,
그 아래에 원문과 개선본의 차이를 붙였습니다.

앞의 두 개는 실제 사용 기록입니다. 원문과 개선본 모두 공개 저장소의 git 이력에서
확인할 수 있습니다. 나머지 세 개는 적용 범위를 보이려고 새로 만든 재현 예시입니다.

| | 문서 | 다룬 문제 |
| --- | --- | --- |
| [1](examples/01-readme-template-fe.diff) | 리드미 (실사용) | 비ASCII 문장부호, 비유적 어휘, 음차된 기술 용어, 들쭉날쭉한 강조 |
| [2](examples/02-readme-gh-todoist-sync.diff) | 리드미 (실사용) | 구어체 서술, 1인칭 시점, 접속 관계 미표시 |
| [3](examples/03-prd.diff) | 기획 문서 | 명사구 종결, `~의` 남용, 음차 어휘 |
| [4](examples/04-report.diff) | 분석 리포트 | 피동 남용, 번역투, 사라진 주어 |
| [5](examples/05-blog.diff) | 블로그 글 | 비유 남발. 명령형과 문체는 그대로 두는 사례 |

5번은 격식 없는 글에 적용했을 때 글의 목소리가 사라지지 않는지 확인하는 예시입니다.
이 스킬은 문체를 지정하지 않고, 원문이 고른 문체 안에서 문장을 완성시킵니다.
