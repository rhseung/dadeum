# 예시 4. 분석 리포트

재현 예시입니다. 피동 표현과 번역투가 겹쳐 주어가 사라지는, 리포트에서 특히 잦은
형태를 다뤘습니다.

## 원문

```markdown
# 3분기 이탈률 분석

## 요약

3분기 이탈률은 전분기 대비 2.4%p 상승하였다. 주요 원인으로는 온보딩 플로우의
복잡도의 증가가 지목된다. 또한 결제 단계에서의 이탈이 관찰되었다.

## 상세

- 온보딩: 스텝이 4개 → 7개로 늘어남. 완료율 68% → 51%
- 결제: 카드 등록 실패 시 리커버리 플로우 부재
- 모바일: 로딩이 느려서 유저가 떠남

## 제언

온보딩 스텝의 축소가 우선적으로 검토되어야 한다. 결제 실패에 대한 재시도 UI 추가도
필요하다고 판단된다.
```

## 개선본

```markdown
# 3분기 이탈률 분석

## 요약

3분기 이탈률이 전분기보다 2.4%p 올랐다. 가장 큰 원인은 온보딩 과정이 복잡해진
것이다. 결제 단계에서도 이탈이 나타났다.

## 세부 내용

- 온보딩 단계가 4개에서 7개로 늘었고, 완료율은 68%에서 51%로 떨어졌다.
- 결제에서 카드 등록에 실패했을 때 다시 시도할 수 있는 경로가 없다.
- 모바일에서는 화면이 늦게 떠서 사용자가 이탈한다.

## 개선 제안

온보딩 단계를 먼저 줄여야 한다. 결제에 실패한 사용자가 다시 시도할 수 있는 화면도
함께 추가해야 한다.
```

## 무엇이 바뀌었나

| 규칙 | 원문 | 개선본 |
| --- | --- | --- |
| 피동 남용 | `원인으로는 ... 증가가 지목된다` | `가장 큰 원인은 ... 복잡해진 것이다` |
| 피동 남용 | `이탈이 관찰되었다` | `이탈이 나타났다` |
| 피동 남용 | `축소가 우선적으로 검토되어야 한다` | `단계를 먼저 줄여야 한다` |
| 피동 남용 | `필요하다고 판단된다` | `함께 추가해야 한다` |
| `~의` 남용 | `온보딩 플로우의 복잡도의 증가` | `온보딩 과정이 복잡해진 것` |
| 번역투 | `전분기 대비`, `결제 단계에서의 이탈` | `전분기보다`, `결제 단계에서도 이탈이` |
| 번역투 | `결제 실패에 대한 재시도 UI` | `결제에 실패한 사용자가 다시 시도할 수 있는 화면` |
| 비ASCII 문장부호 | `4개 → 7개`, `68% → 51%` | `4개에서 7개로`, `68%에서 51%로` |
| 종결어미 완성 | `리커버리 플로우 부재`, `유저가 떠남` | `다시 시도할 수 있는 경로가 없다`, `사용자가 이탈한다` |
| 섹션 제목 | `상세` | `세부 내용` |

원문의 `~하였다` 체를 `~한다` 체로 통일했을 뿐, `~합니다` 로 올리지 않았습니다.
문체를 정하는 것은 글쓴이의 몫이고, 이 스킬은 원문에 이미 있는 문체를 일관되게
맞추는 데까지만 관여합니다.
