# 예시 5. 블로그 글

재현 예시입니다. 격식 없는 글에 적용하면 목소리가 사라지지 않는지 확인하려고
넣었습니다.

## 원문

```markdown
# 사이드 프로젝트를 3년 만에 끝낸 이야기

3년 전에 시작한 프로젝트를 드디어 접었다 — 성공해서가 아니라 그만두기로 해서다.

## 배운 것

- **범위를 좁혀라.** 처음엔 모든 걸 다 담으려다 아무것도 못 냈다.
- **혼자 하지 마라.** 리뷰해줄 사람이 없으면 코드가 산으로 간다.
- **일단 내라.** 완벽한 v1은 없다. 내야 피드백이 온다.

결국 제일 큰 문제는 기술이 아니라 스코프였다. 욕심이 프로젝트를 잡아먹은 셈이다.
```

## 개선본

```markdown
# 사이드 프로젝트를 3년 만에 끝낸 이야기

3년 전에 시작한 프로젝트를 드디어 접었다. 성공해서가 아니라 그만두기로 했기 때문이다.

## 교훈

- 범위를 좁혀라. 처음에는 모든 기능을 담으려다가 아무것도 내놓지 못했다.
- 혼자 하지 마라. 코드를 검토해 줄 사람이 없으면 구조가 원래 의도에서 멀어진다.
- 일단 내라. 완벽한 첫 판본은 없다. 내놓아야 피드백이 온다.

가장 큰 문제는 기술이 아니라 범위였다. 욕심이 프로젝트를 감당할 수 없는 크기로 키웠다.
```

## 무엇이 바뀌었나

| 규칙 | 원문 | 개선본 |
| --- | --- | --- |
| 비ASCII 문장부호 | `드디어 접었다 — 성공해서가 아니라` | `드디어 접었다. 성공해서가 아니라` |
| 비유적 어휘 | `코드가 산으로 간다` | `구조가 원래 의도에서 멀어진다` |
| 비유적 어휘 | `욕심이 프로젝트를 잡아먹은 셈이다` | `욕심이 프로젝트를 감당할 수 없는 크기로 키웠다` |
| 조사 복원 | `처음엔 모든 걸 다 담으려다` | `처음에는 모든 기능을 담으려다가` |
| 성분 복원 | `아무것도 못 냈다` | `아무것도 내놓지 못했다` |
| 섹션 제목 | `배운 것` | `교훈` |
| 강조 기준 | 항목 앞머리에만 붙은 굵은 강조 | 제거 |
| 음차 어휘 | `스코프` | `범위` |

## 보존 대상

`범위를 좁혀라`, `혼자 하지 마라`, `일단 내라` 는 명령형 그대로 두었습니다. 명령형
종결어미도 완성된 문장이므로 규칙에 걸리지 않고, 이 글에서는 그 짧은 호흡이 글의
목소리이기 때문입니다.

`~다` 체도 `~합니다` 로 올리지 않았습니다. 이 스킬은 문체를 지정하지 않고, 원문이
고른 문체 안에서 문장을 완성시킵니다.

`욕심이 프로젝트를 ... 키웠다` 는 여전히 비유입니다. 규칙 4-3 이 금지하는 것은 평범한
어휘가 놓일 자리를 비유가 대신하는 경우이고, 여기서는 비유가 글의 논지 자체입니다.
`잡아먹었다` 만 뜻이 흐려 바꿨습니다.
